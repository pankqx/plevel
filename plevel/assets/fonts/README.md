# Bundled fonts

- **Inter** (`InterVariable.ttf`), by Rasmus Andersson, SIL Open Font License 1.1: https://github.com/rsms/inter
- **JetBrains Mono** (`JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`), by JetBrains, SIL Open Font License 1.1: https://github.com/JetBrains/JetBrainsMono

Both licenses allow redistribution with the application. Plevel loads them at startup so it looks the same on every machine.
